# pi-tools

Monorepo for Pi extensions, skills, prompts, and themes.

## Packages

- [`pi-impeccable-skill`](./packages/pi-impeccable-skill) — pinned Impeccable design workflows packaged for Pi.
- [`pi-peekaboo`](./packages/pi-peekaboo) — Peekaboo desktop automation for Pi.
- [`pi-web-access-v2`](./packages/pi-web-access-v2) — web search and content access with a configurable Perplexity `BASEURL`.
